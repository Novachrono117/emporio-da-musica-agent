## Notes

- `gemini/gemini-3.5-flash-lite`, prompt caching: not projected: the prefix of about 2,150 tokens is under the 4,096-token minimum Google documents for implicit caching on other Gemini 3 models, and none is documented for Flash-Lite.
- `gemini/gemini-3.8-flash`, prompt caching: not projected, for the same reason as Flash-Lite.
- `gemini/gemini-3.8-flash`: these prices hold through 2026-12-31; from 2027-01-01 they double (1.50 input, 7.50 output).
- `anthropic/claude-haiku-5-5`: prices for prompts up to 100,000 tokens; the agent's prompts stay under 15,000.
- `gemini/gemini-3.8-flash` is not projected: 2 complete conversations, fewer than one run of the golden set.
- Claude Haiku 5.5 was not measured (no API credit): its tokens are Gemini Flash-Lite's plus the tool-use system prompt the API adds to every request. Claude's tokenizer counts the same text differently, and its adaptive thinking adds output tokens that could not be measured here.
- Gemini's OpenAI-compatible endpoint reports thinking only in `total_tokens`, and the evaluation recorded `completion_tokens`. In 8 later calls of the agent Flash-Lite used no thinking at its default level, so its output is taken as complete; the adapter now counts thinking as output.
- Prompt caching, where projected, covers only the system prompt and tool definitions on calls after the first in a conversation; the history can also be cached, so the real saving can be larger.
